# 多语言约定

- 所有用户可见文案（含窗口标题、工具提示、无障碍描述和后续错误提示）使用 Compose Resources，禁止在 UI 代码中直接写展示文案。
- 默认资源 `composeApp/src/commonMain/composeResources/values/strings.xml` 为英文回退；`values-zh/strings.xml` 为中文。目前跟随系统语言，不提供应用内切换。
- 使用语义明确、稳定的资源键；新增语言在对应 `values-语言代码` 目录中提供翻译。
- 分类与业务状态使用稳定标识，不能用翻译后的文案做条件判断、持久化键或同步值。
- 数量使用 plurals，动态数据使用资源占位符，避免拼接句子。
- 用户输入、文件名、角色名和自定义标签属于用户数据，不自动当作界面文案翻译。
- 验收时检查中英文布局；允许文本换行，不能依赖中文字符长度确定组件尺寸。
